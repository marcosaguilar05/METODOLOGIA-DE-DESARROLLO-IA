# Contribuir a GASE

GASE v0.1 es una baseline experimental.

## Tipos de contribución

### Observación
Algo ocurrió durante el uso real de la metodología.

Crear `METH-OBS`.

### Propuesta
Se propone modificar la metodología.

Crear `METH-PROP`.

## Regla

Una propuesta no modifica automáticamente GASE v0.1.

Debe indicar:

- problema observado;
- impacto;
- evidencia disponible;
- cambio propuesto;
- garantías que conserva;
- posibles efectos secundarios.

La simplificación debe respetar:

> Reducir burocracia, no garantías.
