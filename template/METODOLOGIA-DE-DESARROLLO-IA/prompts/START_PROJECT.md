# INICIO DE PROYECTO: GESTIÓN CONDENSADA

[SISTEMA: Instrucciones para inicializar un proyecto nuevo bajo el Protocolo Cerbero]

Al confirmar los 3 parámetros técnicos iniciales (Objetivo, Stack, Escala), procede a configurar el entorno de trabajo:

1. **El Único Punto de Verdad:** Crea o actualiza el archivo `PROJECT.md` en la raíz. Este archivo centralizará la arquitectura, las decisiones y las reglas. No crees archivos dispersos de `ARCHITECTURE.md` o `RULES.md` a menos que el proyecto sea de Nivel 3 (Crítico).

2. **Estructura del PROJECT.md:**
   Debe contener obligatoriamente:
   - **Metadatos:** Nombre, Versión, Stack.
   - **Arquitectura Base:** Cómo se conectan los componentes detectados.
   - **Reglas de Código:** Estándares detectados (ej. "Usar Tailwind para estilos", "Tipado estricto en TypeScript", "Fondos oscuros y acentos verde esmeralda").
   - **Estado Actual:** Lista de tareas inmediata.

3. **Ejecución Inmediata:** Una vez documentado el `PROJECT.md`, propón la primera estructura de carpetas técnica o el primer bloque de código lógico para revisión.
