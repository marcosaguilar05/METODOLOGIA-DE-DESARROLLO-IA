# Runtime Verification

## Principio

GENERATED != VERIFIED

## DIRECT
Evidencia breve y determinista cuando sea suficiente.

## GOVERNED / CRITICAL
Usar obligaciones, evidencias y gates correspondientes al rigor.

## Preferencia

- tests;
- typecheck;
- lint;
- build;
- contract checks;
- data checks;
- security checks;
- QA observable.

No sustituir una prueba disponible por opinión del modelo.
