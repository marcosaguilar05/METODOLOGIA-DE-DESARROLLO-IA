# Deliverables

Esta carpeta contiene vistas generadas del Engineering State para entrega, revisión o distribución.

Ejemplos:

- Especificación de requisitos DOCX/PDF
- Documento de arquitectura
- Documento funcional
- Manual de usuario
- Informe de validación

Los entregables no deben convertirse en una segunda fuente de verdad divergente.

La fuente operativa vive en los artefactos Markdown y el Engineering State.
