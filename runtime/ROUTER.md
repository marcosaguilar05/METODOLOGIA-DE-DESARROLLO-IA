# Runtime Router

## Entrada

1. `GASE_CONTROL.md`
2. `gase.config.yaml`
3. `runtime/CONTEXT_COMPILER.md`
4. `runtime/SKILL_REGISTRY.md`

## Clases

### READ_ONLY
Consulta/análisis sin cambio persistente.

### DIRECT
Cambio local, reversible, bajo impacto y verificable.

### GOVERNED
Cambio material en comportamiento, contratos, datos, reglas, arquitectura,
seguridad, integraciones o múltiples superficies.

### CRITICAL
Cambio de alta criticidad o irreversibilidad.

## Regla

La profundidad visible del proceso debe ser proporcional al riesgo.

El Kernel permanece activo aunque algunos artefactos se compriman físicamente.
