# M-011 — Requisitos y atributos de calidad

Se formalizan requisitos funcionales y no funcionales del futuro motor.

Atributos prioritarios:

- integridad;
- trazabilidad;
- explicabilidad;
- seguridad;
- mantenibilidad;
- extensibilidad;
- usabilidad.

Se identifica la necesidad de no imponer un stack desde la metodología.
