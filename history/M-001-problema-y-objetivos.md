# M-001 — Definición del problema y objetivos

Problema central: la IA puede generar código rápidamente, pero no garantiza por sí sola requisitos, arquitectura, trazabilidad, seguridad, mantenibilidad ni evolución coherente.

Hipótesis inicial: combinar requisitos estructurados, decisiones explícitas, trazabilidad, autoridad y evidencia puede conservar velocidad sin perder control.

Cadena inicial:

`REQ → RULE → DATA → ADR → API → UI → TEST → CODE`
