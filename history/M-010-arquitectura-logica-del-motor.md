# M-010 — Arquitectura lógica del motor

Se propone un Engineering Governance Engine como implementación posible.

Componentes lógicos:

- Artifact Service;
- Graph Service;
- Workflow Orchestrator;
- Impact/Risk/Authority;
- Context Compiler;
- Execution Gateway;
- Evidence Engine;
- Gate Engine;
- Transition Manager.

La arquitectura lógica no obliga a microservicios.
