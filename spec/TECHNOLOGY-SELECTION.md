# Selección tecnológica por proyecto

GASE no posee stack preferido.

## Proceso

```text
NEED
→ TRP (Technology Requirement Profile)
→ CANDIDATES
→ MANDATORY FILTER
→ TRADE-OFFS
→ SPIKE / EVIDENCE
→ AUTHORITY
→ ADR
→ TECH ACTIVE
```

## Reglas

- No agregar una tecnología porque esté de moda.
- No agregar graph DB solo porque exista un grafo conceptual.
- No agregar vector DB solo porque exista IA.
- No agregar microservicios sin una necesidad que justifique la complejidad.
- No agregar IA al producto si el producto no la necesita.
- Las decisiones difíciles de revertir requieren mayor evidencia.
