# Modelo de artefactos

## Identidad

Formato recomendado:

```text
TYPE-NNNN
```

Ejemplos:

- REQ-0001
- RULE-0003
- ADR-0002
- TASK-0010
- EVID-0007
- CHG-0004

La identidad permanece; la versión puede cambiar.
